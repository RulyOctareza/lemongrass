# Writing a book chapter

Pick where the chapter goes from `biblio/books/toc.md`, preferring the earlier option:

1. **An existing chapter covers the subject.** Correct or extend it in place.
2. **A book's tags cover the subject.** Add a chapter to that book.
3. **No book's tags fit.** Start a new book, a folder of its own with its own toc line.
4. **Split.** If the new chapter needs tags the book's other chapters do not share, or the book now holds two subjects a reader would look for separately, move those chapters into a new book and give each book its own toc line and tags.

Never start a one-chapter book for a subject an existing book already covers.
